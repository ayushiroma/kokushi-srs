# 得意・苦手ページの試験別分離 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 「得意・苦手」ページ(`kokushi-weakness`コードブロック)の一番上に看護師/保健師を切り替えるドロップダウンを1つ置き、必修・分野別・トピック別ワーストの全セクションを選んだ試験だけに絞り込んで表示する。デフォルトは看護師。

**Architecture:** `core/fields.ts`に「Vaultに実際にある試験の一覧を、決まった表示順で返す」純関数を1つ追加する。`obsidian/weaknessBlock.ts`側は、既存の`registerPickerBlock`(`pickerBlock.ts`)と同じ「選択状態が変わったら`el.empty()`して丸ごと再描画する」パターンで、選んだ試験の`questions`だけを`aggregateWeakness`等の既存関数に渡す。集計ロジック(`core/weakness.ts`)自体は変更しない。

**Tech Stack:** TypeScript, Obsidian Plugin API, vitest（`npm test` = `tsc --noEmit && vitest run`）

## Global Constraints

- `src/core/`配下は純関数のみで、Obsidian API(`obsidian`パッケージ)に依存させない。UIの組み立ては`src/obsidian/`側でやる
- 表示名の決め打ち文字列を増やさない。既存の`examLabel`（`src/core/fields.ts`）を使う
- 新しいボタン・画面を増やさない
- 前回選択した試験を記憶しない。ページを開くたびに看護師をデフォルト表示にする

```typescript
/**
 * 得意・苦手ページの試験切り替えドロップダウンで使う一覧。
 *
 * `config.scope` は現状どこからも参照されておらず、Vaultの実際の問題データと
 * ズレていても検知できない。代わりに実際に存在する `exam` の値から作ることで、
 * 設定ファイルとVaultの中身が食い違う心配を無くす（knowledgeMap.tsの並び替えと同じ考え方）。
 */
export function presentExams(exams: readonly string[]): string[] {
  const unique = [...new Set(exams)]
  return unique.sort((a, b) => {
    const ia = EXAM_ORDER.indexOf(a)
    const ib = EXAM_ORDER.indexOf(b)
    if (ia !== ib) {
      return (ia === -1 ? Number.MAX_SAFE_INTEGER : ia) - (ib === -1 ? Number.MAX_SAFE_INTEGER : ib)
    }
    return a.localeCompare(b)
  })
}
```

- [ ] **Step 2: `registerWeaknessBlock`本体を書き換える**

既存の`export function registerWeaknessBlock`全体（108〜152行目）を、以下に置き換える。

やっていることの要点：
- データの読み込み（`config` / `entries` / `states` / `questions`）は試験を切り替えても変わらないので、外側の`async`コールバックで1回だけ行う
- 中に`draw(exam: string)`という同期関数を作り、これが「選ばれた試験だけに絞ったDOMを描く」処理を担当する。ドロップダウンの`onchange`から呼び出す
- 初期表示の試験は `presentExams(...)`の先頭。看護師のデータがある限り`EXAM_ORDER`の並びにより必ず先頭は`nurse`になる（Task 1のテスト「重複を除いてEXAM_ORDERの順に並べる」で保証済み）

```typescript
export function registerWeaknessBlock(plugin: KokushiPlugin): void {
  plugin.registerMarkdownCodeBlockProcessor('kokushi-weakness', async (source, el) => {
    try {
      el.empty()
      const topicLimit = parseIntField(source, 'topics', DEFAULT_TOPIC_LIMIT)

      const config = await loadConfig(plugin.app)
      const examDate = earliestExamDate(config)
      const entries = await plugin.logStore.readAll()
      const states = buildStates(entries)
      const questions = indexQuestions(plugin.app)

      if (questions.length === 0) {
        el.createEl('p', { text: '問題ノートがありません' })
        return
      }

      const exams = presentExams(questions.map((q) => q.exam))
      if (exams.length === 0) {
        el.createEl('p', { text: '問題ノートがありません' })
        return
      }

      const selectWrap = el.createDiv({ cls: 'kokushi-picker-item' })
      selectWrap.createEl('label', { text: '試験' })
      const select = selectWrap.createEl('select', { cls: 'kokushi-select' })
      for (const exam of exams) {
        const optionEl = select.createEl('option', { text: examLabel(exam) })
        optionEl.value = exam
      }

      const body = el.createDiv()

      const draw = (exam: string): void => {
        body.empty()
        const examQuestions = questions.filter((q) => q.exam === exam)

        renderHisshu(body, examQuestions, entries, config.hisshu)

        body.createEl('p', { text: `${examLabel(exam)} 分野別（全体像）`, cls: 'kokushi-section-title' })
        renderRows(
          body,
          aggregateWeakness(examQuestions.map((q) => ({ key: q.field, id: q.id })), states, examDate),
          plugin,
          'field',
        )

        body.createEl('p', {
          text: `10分で潰すならここ（${examLabel(exam)} トピック別ワースト${topicLimit}）`,
          cls: 'kokushi-section-title',
        })
        const topicRows = aggregateWeakness(
          examQuestions.flatMap((q) => q.tags.map((tag) => ({ key: tag, id: q.id }))),
          states,
          examDate,
        ).filter((row) => row.weak > 0)
        renderRows(body, topicRows.slice(0, topicLimit), plugin, 'tag')
      }

      select.value = exams[0]
      select.onchange = () => draw(select.value)
      draw(exams[0])
    } catch (error) {
      el.empty()
      el.createEl('p', { text: RENDER_ERROR })
      console.error('kokushi-srs: 表示に失敗しました', error)
    }
  })
}
```
